## Question 5: What are Calculated Insights in Data Cloud?

### Answer

Calculated Insights are computed metrics and predictions generated by Data Cloud from the underlying data. They provide actionable intelligence that agents can use to personalize interactions and make data-driven decisions.

### Architecture Explanation

**Calculated Insights Types**

1. **Descriptive Insights**
   - Summarize historical data
   - Example: "Total purchases: $15,000", "Average order value: $500"

2. **Predictive Insights**
   - Predict future outcomes using ML models
   - Example: "Churn Risk: High", "Upsell Probability: 85%"

3. **Prescriptive Insights**
   - Recommend actions based on predictions
   - Example: "Recommend: Offer 10% discount to prevent churn"

4. **Diagnostic Insights**
   - Explain why something happened
   - Example: "Churn risk increased because last purchase was 90 days ago"

**Insight Generation Process**

1. Data is collected from multiple sources
2. Data is processed and transformed
3. ML models are applied for predictions
4. Insights are calculated and stored
5. Insights are available for grounding in Agentforce

**Insight Configuration**
- Insight types are configured per Data Space
- ML models are trained on historical data
- Insight refresh schedules are configured
- Insight accuracy is monitored

### Real-World Example

A customer profile with Calculated Insights:

**Descriptive**: Total purchases: $15,000, Average order value: $500, Last purchase: 30 days ago
**Predictive**: Churn Risk: Low (0.15), Upsell Probability: High (0.82)
**Prescriptive**: Recommend: Premium upgrade offer
**Diagnostic**: Low churn risk because of recent purchase activity and high engagement

### Common Mistakes

- Not configuring insights for key metrics
- Not refreshing insights regularly
- Not using insights in Agentforce grounding
- Ignoring insight accuracy

### Interview Tips

- Explain the types of insights
- Provide a concrete example
- Emphasize the connection to Agentforce grounding
- Connect insights to business outcomes
